# Getting Started

This sample docs set is built to work in two places:

- embedded under FastAPI at `/help`
- deployed as a standalone static site on GitHub Pages or Cloudflare Pages

The links stay relative to the deployment, so the same build can move between hosts without editing paths.

## What to try

![Example documentation illustration](../assets/images/docs-demo.svg)

1. Open the [Queue Page](../features/queue-page.md) and follow the internal links.
2. Read [Create AI Karaoke](../tasks/create-ai-karaoke.md) for a short workflow example.
3. Visit [Troubleshooting](../troubleshooting/index.md) to verify cross-page navigation.
