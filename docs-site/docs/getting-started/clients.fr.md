## Client étape { #stage-client }
Le client de la scène est responsable de l'affichage des paroles et de la vidéo du karaoké au public.

Les systèmes d'exploitation **Desktop** (Windows, Linux, macOS), tels qu'un ordinateur portable ou un ordinateur de bureau, sont recommandés, en particulier pour l'affichage sur un téléviseur ou un projecteur.

Les appareils Android sont pris en charge, mais peuvent nécessiter une configuration de thème de scène supplémentaire pour mieux s'afficher sur une petite fenêtre.

Les appareils iOS/iPadOS ne prennent pas en charge l'intégralité des fonctionnalités du client de scène, en raison des limitations Apple sur les navigateurs web, ces appareils ne peuvent pas lire 2 flux audio simultanément.

En outre, les navigateurs sur certains appareils Apple plus anciens ne prennent en charge que les médias H.264 + AAC, alors voir le [Conseils d'affichage pour iPhone et iPad](../tasks/stage-and-branding.md#use-an-iphone-or-ipad-as-a-stage-display).

## Clients invités { #guest-clients }
Tout appareil avec un navigateur web moderne fonctionnera à la recherche, la file d'attente et le contrôle des médias karaokés.

Si l'isolement du client Wi-Fi (ou du réseau invité) est utilisé, envisagez d'utiliser un proxy inverse et activez le hairpin NAT sur votre routeur. Plus de configuration réseau est couvert dans [administration du serveur](../tasks/server-administration.md).

Pour un appareil partagé, une tablette ou un ordinateur portable est approprié. Envisager de permettre le mode kiosque pour empêcher les clients de quitter l'application.

[Mode Kiosque iPad](https://support.apple.com/en-us/111795)

[Appli Kiosque Android](https://github.com/RushB-fr/freekiosk)
