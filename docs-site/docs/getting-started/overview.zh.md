# 快速开始

这个示例文档集要在两种位置都能工作：

- 作为 FastAPI 的 `/help` 内嵌页面
- 作为 GitHub Pages 或 Cloudflare Pages 的独立静态站点

链接会保持相对部署路径，因此同一份构建产物可以直接移动到不同主机。
