## Bienvenido

DMKaraoke (Demucs Karaoke App) es una aplicación web ligera para karaoke en casa. Utiliza aprendizaje automático para separar las voces y crear letras sincronizadas palabra por palabra. La aplicación es **completamente gratuita**, **sin anuncios** y **sin cuotas de suscripción en la nube**. Crea el karaoke en tu propio dispositivo.
