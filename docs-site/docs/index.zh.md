## 欢迎光临 { #welcome }

DMKaraoke（Demucs Karaoke App）是一款面向家庭使用的轻量级网络卡拉 OK 应用。它使用机器学习分离人声，并生成逐字同步的歌词。应用**完全免费**、**没有广告**、**不收取云订阅费用**，所有卡拉 OK 内容都在您自己的设备上生成。
