# 队列页面 { #queue-page }

队列页面是应用在手机和平板电脑上的主要控制界面。

![队列页面](../assets/images/queue.webp)

## 要点 { #highlights }

<div class="grid cards" markdown>

-   ![从队列控制舞台](../assets/images/queuepage.gif)

    __控制舞台__

    播放、暂停或拖动当前媒体进度，并从队列页面管理伴唱人声轨道。

    - 播放、暂停、跳过或查找当前媒体。
    - 应用共享的歌词预设。
    - 更改歌词文字大小、宽度和背景。
    - 启用或禁用伴唱人声轨道，并调整其音量。

-   ![队列曲目](../assets/images/queuesong.gif){ height="250" }

    __队列控件__

    使用手机或平板电脑搜索歌曲、添加歌曲，并管理当前队列。

</div>

## 你可以做点什么 { #what-you-can-do }

<div class="grid cards" markdown>

-   :material-account-plus:{ .lg .middle } __作为嘉宾加入并排队__

    ---

    选择显示名称或使用自动生成的名称，查看当前在线用户，并将歌曲添加到共享队列。
    ![作为嘉宾加入并排队](../assets/images/queue/herenow.webp)

-   :material-magnify:{ .lg .middle } __搜索本地媒体和 YouTube__

    ---

    同时搜索本地媒体库和 YouTube。启用后，应用还会同时搜索歌曲原名和卡拉 OK 版本。
    ![搜索当地媒体和YouTube](../assets/images/queue/search.webp)

-   :material-remote:{ .lg .middle } __控制舞台__

    ---

    播放、暂停或拖动当前媒体进度，并从队列页面管理伴唱人声轨道。
    ![控制舞台](../assets/images/queue/control.webp)

-   :material-text-box-outline:{ .lg .middle } __使用歌词查看器__

    ---

    直接在设备上查看当前歌词；对于中文歌词，还可以选择拼音视图。
    ![歌词查看器](../assets/images/lyrics-viewer.webp)

-   :material-shield-account-outline:{ .lg .middle } __使用正确的访问级别__

    ---

    来宾可以管理自己加入队列的歌曲，管理员则可以代表其他用户添加歌曲，并管理整个队列。

</div>
