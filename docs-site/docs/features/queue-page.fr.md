# Demande de renseignements Page { #queue-page }

La page de file d'attente est la principale surface de commande mobile/tablet pour l'application.

![Demande de renseignements Page](../assets/images/queue.webp)

## Faits saillants { #highlights }

<div class="grid cards" markdown>

-   ![Contrôle de l'étape depuis la file d'attente](../assets/images/queuepage.gif)

__Contrôlez l'étape__

Jouez, arrêtez ou cherchez les médias actuels, et gérez les pistes de sauvegarde vocales depuis la page de la file d'attente.

    - Jouez, arrêtez, sautez ou cherchez les médias actuels.
    - Appliquer les presets lyriques partagés.
    - Changer la taille, la largeur et le fond du texte lyrique.
    - Activer ou désactiver les pistes de sauvegarde vocale et ajuster leur volume.

-   ![Enquêté](../assets/images/queuesong.gif){ height="250" }

__Quue commandes__

Rechercher, ajouter des chansons et gérer la file d'attente active depuis un téléphone ou une tablette.

</div>

## Ce que vous pouvez faire { #what-you-can-do }

<div class="grid cards" markdown>

-   :material-account-plus:{ .lg .middle } __Rejoindre la session et mettre une chanson en file__

    ---

Choisissez un nom d'affichage ou utilisez un nom généré, voyez qui est présent, et ajoutez des chansons à la file d'attente partagée.
![Rejoignez et file d'attente en tant qu'invité](../assets/images/queue/herenow.webp)

-   :material-magnify:{ .lg .middle } __Rechercher dans les médias locaux et sur YouTube__

    ---

Une fois activée, l'application recherche aussi un titre de chanson et une version karaoké.
![Rechercher les médias locaux et YouTube](../assets/images/queue/search.webp)

-   :material-remote:{ .lg .middle } __Contrôler la scène__

    ---

Jouez, arrêtez ou cherchez les médias actuels, et gérez les pistes de sauvegarde vocales depuis la page de la file d'attente.
![Contrôler l'étape](../assets/images/queue/control.webp)

-   :material-text-box-outline:{ .lg .middle } __Utiliser le lecteur de paroles__

    ---

Lisez les paroles actuelles directement sur l'appareil, avec une vue en option Pinyin pour les paroles chinoises.
![Vueur de lyriques](../assets/images/lyrics-viewer.webp)

-   :material-shield-account-outline:{ .lg .middle } __Utiliser le niveau d’accès approprié__

    ---

Les clients peuvent gérer leurs propres chansons en file d'attente, tandis que les administrateurs peuvent faire la queue au nom d'un autre utilisateur et gérer la file d'attente complète.

</div>
