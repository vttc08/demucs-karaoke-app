# Stage Display

The stage display shows the current performance and provides controls for managing the stage.

![Stage Display](../assets/images/stage.webp)

## Highlights
<div class="grid cards" markdown>
-   ![Stage control from queue](../assets/images/queuepage.gif)

    __Real-time control__

    Control the current performance from the stage display or queue page.

    - Play, pause, skip, or seek the current media.
    - Apply shared lyric presets.
    - Change lyric text size, width, and background.
    - Enable or disable vocal backing tracks and adjust their volume.

-   ![Customization](../assets/images/stage/customization.gif)

    __Advanced lyrics style customization__

    Customize the appearance and animation of lyrics for a polished stage experience.

    - Change the text size, width, color, and background of the lyrics.
    - Choose from hundreds of fonts through Google Fonts.
    - Customize scroll animations for word-by-word lyrics.
    - Easily share and recreate lyric presets via JSON.

-   ![Keyboard shortcuts](../assets/images/stage/shortcuts.gif)

    __Keyboard shortcut navigation__

    Quickly control the stage display with a keyboard, including while using Zen mode.

    - Change vocals, lyrics, and playback.
    - Display and adjust the QR code.
    - Use the shortcuts without on-screen controls in Zen mode.
</div>

## What you can do

-   :material-sync:{ .lg .middle } __Resync playback__

    ---
