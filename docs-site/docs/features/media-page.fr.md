# Page médias { #media-page }

La page médias est pour gérer la bibliothèque d'applications et modifier les chansons téléchargées, et télécharger de nouveaux médias.

![Page médias](../assets/images/media.webp)

## Faits saillants { #highlights }

<div class="grid cards" markdown>

-   ![Contrôle de l'étape depuis la file d'attente](../assets/images/media/external.gif)

__Manage support externe__

Télécharger les médias via l'application ou externement.

    - Télécharger des pistes vidéo et audio via l'application.
    - Exécutez la séparation vocale et créez du karaoké à partir des téléchargements.
    - Détecter les fichiers et les actifs gérés par d'autres applications.
    - Exportez rapidement les médias pour les sauvegarder ou les partager.

-   ![Enquêté](../assets/images/media/create.gif)

__Créer un karaoké AI à partir des médias existants__

Supprimez les paroles vocales et créez des paroles de karaoké de tout média existant dans la bibliothèque.

    - Pas besoin de suivre le processus de téléchargement YouTube.
    - Exécutez la séparation vocale sur les pistes existantes.
    - Rechercher des paroles pour créer des timings précis de karaoké.
    - Télécharger, renommer et supprimer les fichiers sidecar pour karaoké.

-   ![Pilote automatique](../assets/images/media/autopilot.gif)

__Upload autopilot__

Ensemble par défaut d'options qui préparent les paramètres de traitement du karaoké en un seul clic.

    - Inférer automatiquement les informations de suivi en fonction du nom du fichier.
    - Recherche automatique et téléchargement des paroles pour la piste.
    - Remplir automatiquement le titre, l'artiste et les options de traitement de karaoké.
    - Créez des paramètres optimisés de traitement du karaoké en un clic avant de soumettre.

</div>

## Ce que vous pouvez faire { #what-you-can-do }

<div class="grid cards" markdown>

-   :material-filter-variant:{ .lg .middle } __Rechercher et filtrer les médias__

    ---

Rechercher dans toute la bibliothèque des chansons et des filtres en fonction de la voix ou des paroles synchronisées.

-   :material-playlist-plus:{ .lg .middle } __Mettre directement en file depuis les médias__

    ---

Queue chansons pour la lecture pendant la navigation dans la médiathèque.

-   :material-refresh:{ .lg .middle } __Analyser et actualiser la bibliothèque__

    ---

Détecter les changements dans le système de fichiers ou les chansons individuelles et mettre à jour la bibliothèque en conséquence.

-   :material-rename-box:{ .lg .middle } __Renommage intelligent__

    ---

Utilisez LastFM pour déduire automatiquement le titre de piste et l'artiste des titres YouTube.

-   :material-tune:{ .lg .middle } __Options avancées__

    ---

Personnalisez les paramètres des options d'alignement des paroles WhisperX sur les supports existants ou les téléchargements.

</div>
