# Página de medios

La página de medios sirve para gestionar la biblioteca de la aplicación, modificar canciones descargadas y subir nuevos archivos multimedia.

![Página de medios](../assets/images/media.webp)

## Aspectos destacados

<div class="grid cards" markdown>

-   ![Control del escenario desde la cola](../assets/images/media/external.gif)

    __Gestiona medios externos__

    Sube archivos multimedia desde la aplicación o externamente.

    - Sube pistas de vídeo y audio desde la aplicación.
    - Ejecuta la separación vocal y crea karaoke a partir de archivos subidos.
    - Detecta archivos y recursos gestionados por otras aplicaciones.
    - Exporta rápidamente archivos multimedia para hacer copias de seguridad o compartirlos.

-   ![Añadir canción a la cola](../assets/images/media/create.gif)

    __Crea karaoke con IA a partir de medios existentes__

    Elimina las voces y crea letras de karaoke desde cualquier archivo multimedia existente en la biblioteca.

    - No es necesario seguir el proceso de descarga de YouTube.
    - Ejecuta la separación vocal en pistas existentes.
    - Busca letras para crear sincronizaciones de karaoke precisas.
    - Descarga, cambia el nombre y elimina archivos auxiliares de karaoke.

-   ![Piloto automático](../assets/images/media/autopilot.gif)

    __Piloto automático al subir__

    Un conjunto predeterminado de opciones que prepara la configuración de procesamiento de karaoke con un clic.

    - Infiere automáticamente la información de la pista a partir del nombre de archivo.
    - Busca y descarga automáticamente las letras de la pista.
    - Rellena automáticamente el título, el artista y las opciones de procesamiento de karaoke.
    - Crea una configuración de procesamiento de karaoke optimizada con un clic antes de enviarla.

</div>

## Qué puedes hacer

<div class="grid cards" markdown>

-   :material-filter-variant:{ .lg .middle } __Buscar y filtrar medios__

    ---

    Busca canciones en toda la biblioteca y filtra según si la pista tiene voces o letras sincronizadas.

-   :material-playlist-plus:{ .lg .middle } __Añadir directamente desde medios a la cola__

    ---

    Añade canciones para su reproducción mientras exploras la biblioteca multimedia.

-   :material-refresh:{ .lg .middle } __Examinar o actualizar la biblioteca__

    ---

    Detecta cambios en el sistema de archivos o en canciones individuales y actualiza la biblioteca según corresponda.

-   :material-rename-box:{ .lg .middle } __Cambio de nombre inteligente__

    ---

    Usa LastFM para inferir automáticamente el título y el artista de la pista a partir de títulos de YouTube.

-   :material-tune:{ .lg .middle } __Opciones avanzadas__

    ---

    Personaliza los parámetros de las opciones de alineación de letras de WhisperX para medios existentes o archivos subidos.

</div>
