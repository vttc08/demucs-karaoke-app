# Pantalla del escenario

La pantalla del escenario muestra la actuación actual y ofrece controles para gestionarla.

![Pantalla del escenario](../assets/images/stage.webp)

## Aspectos destacados
<div class="grid cards" markdown>
-   ![Control del escenario desde la cola](../assets/images/queuepage.gif)

    __Control en tiempo real__

    Controla la actuación actual desde la pantalla del escenario o la página de cola.

    - Reproduce, pausa, omite o salta a un punto del contenido actual.
    - Aplica preajustes de letras compartidos.
    - Cambia el tamaño, el ancho y el fondo del texto de las letras.
    - Activa o desactiva las pistas de acompañamiento vocal y ajusta su volumen.

-   ![Personalización](../assets/images/stage/customization.gif)

    __Personalización avanzada del estilo de las letras__

    Personaliza el aspecto y la animación de las letras para ofrecer una experiencia de escenario cuidada.

    - Cambia el tamaño, el ancho, el color y el fondo del texto de las letras.
    - Elige entre cientos de fuentes a través de Google Fonts.
    - Personaliza las animaciones de desplazamiento para las letras palabra por palabra.
    - Comparte y recrea fácilmente preajustes de letras mediante JSON.

-   ![Atajos de teclado](../assets/images/stage/shortcuts.gif)

    __Navegación mediante atajos de teclado__

    Controla rápidamente la pantalla del escenario con un teclado, incluso al usar el modo Zen.

    - Cambia las voces, las letras y la reproducción.
    - Muestra y ajusta el código QR.
    - Usa los atajos sin controles en pantalla en el modo Zen.
</div>

## Qué puedes hacer

<div class="grid cards" markdown>

-   :material-play-pause:{ .lg .middle } __Controlar la reproducción__

    ---

    Reproduce, pausa, salta a un punto u omite el contenido actual desde la pantalla del escenario o la página de cola.

-   :material-fullscreen:{ .lg .middle } __Usar el modo Zen__

    ---

    Oculta todos los controles para disfrutar de una auténtica experiencia a pantalla completa.

-   :material-qrcode:{ .lg .middle } __Mostrar un código QR__

    ---

    Permite a los invitados unirse a la cola escaneando un código QR desde la pantalla del escenario.

-   :material-sync:{ .lg .middle } __Resincronizar la reproducción__

    ---

    Recupera la sincronización cuando las voces y el acompañamiento instrumental se desajustan.

-   :material-microphone:{ .lg .middle } __Ajustar las pistas de acompañamiento vocal__

    ---

    Activa o desactiva las pistas de acompañamiento vocal y ajusta su volumen.

-   :material-format-letter-case:{ .lg .middle } __Crear y compartir preajustes de letras__

    ---

    Crea, importa y exporta preajustes de letras para distintas canciones y pantallas de escenario.

-   :material-disc:{ .lg .middle } __Compatibilidad con CDG__

    ---

    Reproduce archivos CDG con su audio y sus gráficos de CD.

</div>
