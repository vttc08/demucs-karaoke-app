# Affichage de l'étape { #stage-display }

L'affichage de l'étape montre les performances actuelles et fournit des contrôles pour la gestion de l'étape.

![Affichage de l'étape](../assets/images/stage.webp)

## Faits saillants { #highlights }
<div class="grid cards" markdown>
-   ![Contrôle de l'étape depuis la file d'attente](../assets/images/queuepage.gif)

Contrôle temps réel__

Contrôlez les performances actuelles depuis la page d'affichage ou de file d'attente.

    - Jouez, arrêtez, sautez ou cherchez les médias actuels.
    - Appliquer les presets lyriques partagés.
    - Changer la taille, la largeur et le fond du texte lyrique.
    - Activer ou désactiver les pistes de sauvegarde vocale et ajuster leur volume.

-   ![Personnalisation](../assets/images/stage/customization.gif)

__ Personnalisation avancée du style des paroles__

Personnalisez l'apparence et l'animation des paroles pour une expérience de scène polie.

    - Changer la taille du texte, la largeur, la couleur et le fond des paroles.
    - Choisissez parmi des centaines de polices via Google Fonts.
    - Personnaliser les animations de défilement pour les paroles mot par mot.
    - Partager et recréer facilement des presets lyriques via JSON.

-   ![Raccourcis clavier](../assets/images/stage/shortcuts.gif)

__Clef clavier navigation__

Contrôlez rapidement l'affichage de scène avec un clavier, y compris en utilisant le mode Zen.

    - Changer de voix, de paroles et de lecture.
    - Affiche et règle le code QR.
    - Utilisez les raccourcis sans contrôle à l'écran en mode Zen.
</div>

## Ce que vous pouvez faire { #what-you-can-do }

<div class="grid cards" markdown>

-   :material-play-pause:{ .lg .middle } __Contrôler la lecture__

    ---

Jouez, arrêtez, cherchez ou sautez les médias actuels depuis la page d'affichage ou de file d'attente.

-   :material-fullscreen:{ .lg .middle } __Utiliser le mode Zen__

    ---

Cacher toutes les commandes pour une véritable expérience plein écran.

-   :material-qrcode:{ .lg .middle } __Afficher un code QR__

    ---

Permettre aux invités de rejoindre la file d'attente en scannant un code QR depuis l'affichage de l'étape.

-   :material-sync:{ .lg .middle } __Resynchroniser la lecture__

    ---

Récupérer de la désynchronisation vocale et instrumentale.

-   :material-microphone:{ .lg .middle } __Régler les pistes vocales__

    ---

Activer ou désactiver les pistes de sauvegarde vocale et ajuster leur volume.

-   :material-format-letter-case:{ .lg .middle } __Créer et partager des préréglages de paroles__

    ---

Créez, importez et exportez des presets lyriques pour différentes chansons et affichages de scène.

-   :material-disc:{ .lg .middle } __Prise en charge de CDG__

    ---

Lire les fichiers CDG avec leurs graphiques audio et CD.

</div>
