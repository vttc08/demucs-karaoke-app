# 媒体页面 { #media-page }

媒体页面用于管理应用媒体库、修改已下载的歌曲，以及上传新媒体。

![媒体页面](../assets/images/media.webp)

## 主要功能 { #highlights }

<div class="grid cards" markdown>

-   ![外部管理媒体](../assets/images/media/external.gif)

    __管理媒体__

    通过应用或其他方式上传媒体。

    - 通过应用上传视频和音频轨道。
    - 运行人声分离，并从上传的媒体创建卡拉 OK。
    - 检测由其他应用管理的文件和资源。
    - 快速导出媒体，用于备份或共享。

-   ![从现有媒体创建 AI 卡拉 OK](../assets/images/media/create.gif)

    __从现有媒体创建 AI 卡拉 OK__

    从媒体库中的现有媒体分离人声，并创建卡拉 OK 歌词。

    - 无需经过 YouTube 下载流程。
    - 对现有音轨运行人声分离。
    - 搜索歌词，生成精确的卡拉 OK 时间轴。
    - 下载、重命名和删除卡拉 OK 附属文件。

-   ![上传自动处理](../assets/images/media/autopilot.gif)

    __上传自动处理__

    使用一组选项，在一次点击中准备卡拉 OK 处理设置。

    - 根据文件名自动推断音轨信息。
    - 自动搜索并下载音轨歌词。
    - 自动填写标题、艺人和卡拉 OK 处理选项。
    - 提交前只需点击一次，即可创建优化的卡拉 OK 处理设置。

</div>

## 你可以做什么 { #what-you-can-do }

<div class="grid cards" markdown>

-   :material-filter-variant:{ .lg .middle } __搜索和筛选媒体__

    ---

    搜索整个媒体库中的歌曲，并根据音轨是否包含人声或已同步歌词进行筛选。

-   :material-playlist-plus:{ .lg .middle } __直接从媒体库排队__

    ---

    浏览媒体库时，将歌曲加入播放队列。

-   :material-refresh:{ .lg .middle } __扫描或更新媒体库__

    ---

    检测文件系统或单首歌曲的变化，并相应更新媒体库。

-   :material-rename-box:{ .lg .middle } __智能重命名__

    ---

    使用 Last.fm 根据 YouTube 标题自动推断音轨标题和艺人。

-   :material-tune:{ .lg .middle } __高级选项__

    ---

    自定义现有媒体或上传媒体的 WhisperX 歌词对齐参数。

</div>
