# Página de cola

La página de cola es la interfaz principal de control de la aplicación para dispositivos móviles y tabletas.

![Página de cola](../assets/images/queue.webp)

## Aspectos destacados

<div class="grid cards" markdown>

-   ![Control del escenario desde la cola](../assets/images/queuepage.gif)

    __Controla el escenario__

    Reproduce, pausa o salta a un punto del contenido actual, y gestiona las pistas de acompañamiento vocal desde la página de cola.

    - Reproduce, pausa, omite o salta a un punto del contenido actual.
    - Aplica preajustes de letras compartidos.
    - Cambia el tamaño, el ancho y el fondo del texto de las letras.
    - Activa o desactiva las pistas de acompañamiento vocal y ajusta su volumen.

-   ![Añadir canción a la cola](../assets/images/queuesong.gif){ height="250" }

    __Controles de cola__

    Busca, añade canciones y gestiona la cola activa desde un teléfono o una tableta.

</div>

## Qué puedes hacer

<div class="grid cards" markdown>

-   :material-account-plus:{ .lg .middle } __Unirte y añadir canciones como invitado__

    ---

    Elige un nombre para mostrar o usa uno generado, mira quién está presente y añade canciones a la cola compartida.
    ![Unirse y añadir canciones como invitado](../assets/images/queue/herenow.webp)

-   :material-magnify:{ .lg .middle } __Buscar medios locales y en YouTube__

    ---

    Busca en paralelo en la biblioteca local y en YouTube. Cuando está activada, la aplicación también busca tanto el título de una canción como una versión de karaoke.
    ![Buscar medios locales y en YouTube](../assets/images/queue/search.webp)

-   :material-remote:{ .lg .middle } __Controlar el escenario__

    ---

    Reproduce, pausa o salta a un punto del contenido actual, y gestiona las pistas de acompañamiento vocal desde la página de cola.
    ![Controlar el escenario](../assets/images/queue/control.webp)

-   :material-text-box-outline:{ .lg .middle } __Usar el visor de letras__

    ---

    Lee las letras de la canción actual directamente en el dispositivo, con una vista opcional en pinyin para letras chinas.
    ![Visor de letras](../assets/images/lyrics-viewer.webp)

-   :material-shield-account-outline:{ .lg .middle } __Usar el nivel de acceso adecuado__

    ---

    Los invitados pueden gestionar sus propias canciones en cola, mientras que los administradores pueden añadir canciones en nombre de otro usuario y gestionar toda la cola.

</div>
