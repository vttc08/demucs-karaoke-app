# Troubleshooting

Use this page to sanity-check the docs deployment.

## Quick checks

- Click the language selector and confirm the URL stays under the docs host or mount point.
- Open [Getting Started](../getting-started/overview.md) and verify the image loads.
- Open [Queue Page](../features/queue-page.md) and confirm the backlink works.

## If links still break

Check whether the docs were copied into `static/docs` for FastAPI or published as the top-level static site for GitHub Pages or Cloudflare Pages.
