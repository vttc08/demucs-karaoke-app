# 用户指南

本页面介绍嘉宾加入卡拉 OK 活动时需要了解的基本操作。

## 加入卡拉 OK 活动 { #join-the-karaoke-session }

1. 扫描舞台电视或投影仪上显示的二维码。
2. 如果看不到二维码，请让卡拉 OK 主持人在键盘上按 ++q++ 显示二维码。
3. 根据提示输入昵称。昵称会标识您点播的歌曲，也有助于将您与其他嘉宾区分开来。

??? note "出现拒绝访问错误"

    卡拉 OK 主持人可能限制了队列访问，或者提供了一台供大家使用的平板电脑。请向主持人寻求帮助。

## 将歌曲加入队列 { #queue-a-song }

将歌曲加入队列有几种方式。请选择最符合您要使用的视频或音乐类型的选项。

<div class="grid cards" markdown>

-   ![标准 YouTube 卡拉 OK](../assets/images/regularkaraoke.webp)

    **标准 YouTube 卡拉 OK**

    将现成的卡拉 OK 视频加入队列，无需进行人声分离或歌词对齐。

    [将普通歌曲加入队列](karaoke-tasks.md#queue-a-premade-karaoke-video)

-   ![去除人声的歌词视频](../assets/images/lyricskaraoke.webp)

    **去除人声的歌词视频**

    使用歌词视频，并让应用移除原始人声。

    [将歌词视频加入队列](create-ai-karaoke.md)

-   ![沉浸式卡拉 OK](../assets/images/immersivekaraoke.webp)

    **沉浸式卡拉 OK**

    创建个性化的卡拉 OK 音轨，包括人声分离、同步歌词，以及原始音乐视频或专辑封面。

    [将音乐视频加入队列](create-ai-karaoke.md)

</div>

您也可以[上传自己的音乐文件](create-ai-karaoke.md)，再添加人声分离和同步歌词。

建议先了解可用的队列选项。这样可以根据找到的 YouTube 视频类型选择合适的方式，并了解应用可以对该视频执行哪些处理。

??? tip "加入队列前预览视频"

    搜索后，点击视频标题在新标签页中打开视频。选择处理选项前，先预览视频，确认其中是否已经包含歌词或人声。
