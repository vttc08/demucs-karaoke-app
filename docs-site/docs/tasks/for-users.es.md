# Para usuarios

Esta página cubre lo básico para los invitados que se unen a una sesión de karaoke.

## Únete a la sesión de karaoke { #join-the-karaoke-session }

1. Escanea el código QR que aparece en el televisor o proyector del escenario.
2. Si el código QR no está visible, pide al anfitrión que pulse ++q++ en el teclado para mostrarlo.
3. Introduce un apodo cuando se te solicite. El apodo identifica tus peticiones de canciones y ayuda a distinguirte de otros invitados.

??? note "Aparece un error de acceso denegado"

    Es posible que el anfitrión haya restringido el acceso a la cola o proporcione una tableta compartida. Pídele ayuda.

## Añade una canción a la cola { #queue-a-song }

Hay varias maneras de poner una canción en cola. Elige la opción que mejor se adapte al vídeo o la música que quieres usar.

<div class="grid cards" markdown>

-   ![Karaoke estándar de YouTube](../assets/images/regularkaraoke.webp)

    **Karaoke estándar de YouTube**

    Pon en cola un vídeo de karaoke ya preparado, sin separación de voces ni alineación de letras.

    [Poner en cola una canción sencilla](karaoke-tasks.md#queue-a-premade-karaoke-video)

-   ![Vídeo con letra y eliminación de voces](../assets/images/lyricskaraoke.webp)

    **Vídeo con letra y eliminación de voces**

    Usa un vídeo con letra y deja que la aplicación elimine las voces originales.

    [Poner en cola un vídeo con letra](create-ai-karaoke.md)

-   ![Karaoke envolvente](../assets/images/immersivekaraoke.webp)

    **Karaoke envolvente**

    Crea una pista de karaoke personalizada con separación de voces, letras sincronizadas y el vídeo musical original o la carátula del álbum.

    [Poner en cola un vídeo musical](create-ai-karaoke.md)

</div>

También puedes [cargar tu propio archivo de música](create-ai-karaoke.md) y añadir separación de voces y letras sincronizadas.

Dedica un momento a revisar las opciones de cola disponibles. Te ayudará a elegir la adecuada para el tipo de vídeo de YouTube que encontraste y a entender lo que la aplicación puede hacer con él.

??? tip "Previsualiza un vídeo antes de ponerlo en cola"

    Después de buscar, haz clic en el título del vídeo para abrirlo en una pestaña nueva. Previsualízalo para comprobar si ya contiene letras o voces antes de elegir las opciones de procesamiento.
