# Pour les utilisateurs { #for-users }

Cette page couvre les bases pour les invités qui se joignent à une session de karaoké.

## Rejoignez la session de karaoké { #join-the-karaoke-session }

1. Scannez le code QR affiché sur la télévision de scène ou le projecteur.
2. Si le code QR n'est pas visible, demandez à l'hôte karaoké de presser ++q++ sur le clavier pour l'afficher.
3. Entrez un surnom quand vous êtes invité. Le surnom identifie vos demandes de chanson et aide à vous distinguer des autres invités.

??? note "Un message d’accès refusé s’affiche"

    L'hôte karaoké peut restreindre l'accès à la file d'attente ou fournir une tablette partagée à la place.

## Laisser une chanson { #queue-a-song }

Il y a plusieurs façons d'attendre une chanson. Choisissez l'option qui correspond le mieux à la vidéo ou à la musique que vous voulez utiliser.

<div class="grid cards" markdown>

-   ![Standard YouTube karaoke](../assets/images/regularkaraoke.webp)

**Karaoké YouTube standard**

Saisissez une vidéo de karaoké prête à l'emploi sans séparation vocale ou alignement lyrique.

    [Queue a simple song](karaoke-tasks.md#queue-a-premade-karaoke-video)

-   ![Lyrics video with vocal removal](../assets/images/lyricskaraoke.webp)

** Vidéo lyrique avec suppression vocale**

Utilisez une vidéo de paroles et laissez l'application supprimer les voix originales.

    [Queue a lyrics video](create-ai-karaoke.md)

-   ![Immersive karaoke](../assets/images/immersivekaraoke.webp)

**Karaoké immersif**

Créez une piste de karaoké personnalisée avec séparation vocale, paroles synchronisées, et l'art vidéo ou album original.

    [Queue a music video](create-ai-karaoke.md)

</div>

Vous pouvez également [importer votre propre fichier musical](create-ai-karaoke.md), puis lui ajouter une séparation vocale et des paroles synchronisées.

Prenez un moment pour examiner les options de file d'attente disponibles. Cela vous aidera à choisir la bonne option pour le type de vidéo YouTube que vous avez trouvé et comprendre ce que l'application peut faire avec.

??? tip "Prévisualiser une vidéo avant de la mettre en file"

    Après recherche, cliquez sur le titre vidéo pour l'ouvrir dans un nouvel onglet. Prévisualiser la vidéo pour vérifier si elle contient déjà des paroles ou des voix avant de choisir les options de traitement.
